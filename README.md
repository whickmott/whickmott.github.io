# whickmott.github.io

GitHub Pages site for William Hickmott.

- `/` - site landing page
- `/asteroid/` - Asteroid Mesh Generator

The asteroid generator runs entirely in the visitor's browser. GitHub Pages only serves the static files.

`asteroid/asteroid-v23.wasm` is intentionally not included in this transfer package. Copy the compiled file from the current Raspberry Pi deployment before the first commit.
