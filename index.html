The sky is real.

Stars are projected from J2000 positions in the Yale Bright Star Catalogue for the selected observer location. The browser calculates the current local sidereal time and plots catalogue stars above that location's horizon.

Point size approximates apparent visual magnitude and colour is estimated from the catalogue temperature where available. The triangular colour field above it is procedural and reacts to pointer movement.

This is a visual sky projection rather than a precision astrometry tool.

Arduino Libraries

Open-source Arduino libraries published for use through the Arduino ecosystem, with source and development hosted on GitHub.

SimpleAD9833 ↗ A deliberately simple interface for the AD9833 waveform generator, covering sine, triangle and square-wave output at user-defined frequencies. InfinitePCA9685 ↗ Treats multiple PCA9685 PWM controllers as one Arduino object, including devices distributed across one or more I²C buses. MKSServoCAN ↗ CAN control for MKS SERVO42D/57D closed-loop stepper drivers, including motion, homing, parameters, status and pluggable CAN backends.
